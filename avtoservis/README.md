# LFG — демонстрационный каталог

## Страны марок и логотипы

Все 52 марки распределены без пропусков и повторов по 11 странам: Япония (6), Южная Корея (5), Германия (5), Франция (3), США (4), Россия (10), Китай (15), Беларусь (1), Узбекистан (1), Чехия (1), Швеция (1). Фильтры действуют на главной, в каталоге `/servis/` и в блоках марок на страницах услуг, сохраняя услугу в ссылках.

Критерий — происхождение марки, а не страна сборки каждого экземпляра или страна нынешнего акционера. Поэтому Volvo относится к Швеции, Solaris — к России отдельно от Hyundai, Jetta — к Китаю как отдельная марка. Nordcross отнесён к России по локальному происхождению марки и российскому правообладателю; производство автомобилей в Китае отдельно отмечено в данных. Справочник, пояснения и ссылки на источники находятся в `data/brand-countries.json`.

Для 33 новых марок сохранены логотипы со страницы https://www.avtogermes.ru/servis/ в `img/logo/*-avtogermes.png`. Все 19 исходных логотипов сохранены. `data/brand-logos.json` хранит исходные URL и локальные пути. Сайт использует локальные файлы, без внешней загрузки логотипов. `prepare-logos.cjs` извлекает ссылки из сохранённой страницы `data/avtogermes-source.html`, `download-logos.ps1` загружает только изображения с домена АвтоГЕРМЕС; эти команды не нужны для обычного запуска.

Проверены переключение новых фильтров, возврат ко всем 52 маркам, переход BELGEE из каталога и сохранение планового ТО после выбора китайской марки. `check.cjs` дополнительно проверяет полноту распределения стран и PNG-сигнатуры всех новых логотипов.

## Обновление перелинковки и внутренних блоков

Названия всех услуг в таблице главной ведут на страницы услуг, в том числе после поиска и смены категории. Услуги исходного прайса без точного совпадения в CSV вынесены в `data/home-services.json`, генерируемый `build-data.cjs`. Это отдельное дополнение к 284 неизменённым исходным адресам. Новые страницы используют пространство `/uslugi/lfg/`; например, `/uslugi/lfg/planovoe-to/`. Цены и время сохранены из прайса главной. Похожие названия не объединяются автоматически.

На страницах услуг добавлен блок 52 марок с сохранением услуги в ссылке. Пример: `/uslugi/lfg/planovoe-to/` → `/servis/kia/planovoe-to/` → выбор Rio → `/servis/kia/rio/planovoe-to/`.

`data/faq.json` содержит 7 вопросов для Kia и 9 для Kia Rio. На страницах услуг эти вопросы дополняют FAQ конкретной работы. Непроверенные интервалы ТО и характеристики комплектаций не утверждаются.

На внутренних страницах блок преимуществ содержит заголовок и шесть плиток: три колонки на широком экране, две на планшете и одну на узком мобильном. Фотография удаляется только из внутреннего представления; главная сохраняет исходный блок.

Работа выполнена в существующем прототипе. Главная, её стили, изображения и исходные интерактивные компоненты сохранены. Список марок расширен до 52, ссылки ведут в каталог. Отдельные HTML-файлы для комбинаций не создаются.

## Запуск

В этой папке, при установленном Node.js:

```powershell
node build-data.cjs
node server.cjs
```

Открыть http://127.0.0.1:4173/ . Сервер доступен только локально. Запуск через `file://` не поддерживается: данные загружаются через HTTP. В другом терминале `node check.cjs` проверяет данные, ресурсы и HTTP-маршруты.

## Демо-страницы

- `/` — исходная главная.
- `/servis/` — 52 марки.
- `/servis/kia/`, `/servis/kia/rio/` — марка и модель.
- `/servis/kia/zamena-masla-v-akpp/` — марка и услуга.
- `/servis/kia/rio/zamena-masla-v-akpp/` — модель и услуга.
- `/servis/toyota/`, `/servis/toyota/camry/`.
- `/uslugi/transmissiya/zamena-masla-v-kpp/zamena-masla-v-akpp/` — исходный URL общей услуги.

Остальные марки, модели и услуги открываются универсальными шаблонами по требованию. Обычная навигация браузера обеспечивает прямые ссылки, обновление, назад/вперёд. Сервер возвращает оболочку index.html для маршрутов без расширения, JS выбирает шаблон. Неизвестные маршруты показывают сообщение «Страница не найдена»; HTTP-статус оболочки остаётся 200.

## Файлы и данные

- `index.html` — исходные компоненты; добавлены base, подключение каталога, noindex и скрытие главной на время загрузки внутренней страницы.
- `src/catalog.js` — шаблоны и навигация, фильтры, единая форма, метаданные текущего пути `window.LFGPage`.
- `src/catalog.css` — стили внутренних страниц, существующие переменные дизайна.
- `build-data.cjs` — импорт обоих исходных CSV; исходные строки, порядок, ID, Parent ID, тип и URL сохранены.
- `data/brands.json`, `models.json`, `services.json`, `prices.json` — результат импорта. 52 марки, 475 моделей, 284 исходных URL без дублей. Служебный R16 добавлен для 20 сиротских записей.
- `data/compatibility.json` — проверенные конфигурации и ручные исключения (сейчас пустые), правила ограничений.
- `server.cjs` — локальный сервер с fallback и заголовком noindex.
- `check.cjs` — проверка целостности данных, локальных ресурсов и HTTP-доступности.

Чтобы добавить марку/модель, дополните соответствующий CSV, сохранив стабильные коды и URL, затем запустите импорт. Для услуги заполните строку CSV с уникальными ID, URL и корректным Parent ID. Цены переносятся только при точном совпадении названия с PRICES главной. Нулевые цены сохраняют исходное значение «Бесплатно»; новые цены и длительности не придуманы.

Разные исходные URL имеют одинаковые последние сегменты (например, диагностика двигателя). В оригинальных адресах ничего не меняется. Для маршрута марки такая коллизия разрешается полем `route_slug` с суффиксом ID; услуги не объединяются. Сегменты моделей зарезервированы. Поле `aliases` предусмотрено для вручную проверенных синонимов.

Орфографические ошибки и неоднозначные названия исходного CSV сохранены для сверки с владельцем данных; автоматического объединения похожих услуг нет. Поиск ищет по всему справочнику независимо от выбранной категории, сброс возвращает все категории.

Конфигурации задаются по URL модели в `compatibility.json`: `configurations["/servis/kia/rio/"] = {powertrain, transmission, drive}`. Используйте только подтверждённые значения, иначе `unknown`. Ручной статус задаётся в `overrides[URL_модели][service_id]`: `available`, `not_applicable`, `unknown`. При непроверенной конструкции услуги сопровождаются уточнением комплектации; недоступные скрываются из таблицы. Отдельная карточка недоступной услуги показывает предупреждение. Годы, поколения, двигатели и кузова не выдумывались; переключателя типов кузова без классификации нет. Фото моделей заменены единым силуэтом из исходного проекта.

## Проверки и ограничения

Проверены в браузере восемь внутренних демо-страниц: ровно одна форма и отсутствие пустых href. Проверены переходы Kia → Rio → услуга и Kia → услуга → Rio, Toyota → Camry → Toyota, поиск и пустая выдача, категории, передача контекста, сохранение имени при поиске, валидация формы, FAQ. Проверены ширины 320, 375, 768, 1024 и 1440 px: горизонтального скролла документа нет, вкладки прокручиваются внутри блока. Отзывы используют исходный внешний виджет и его карусель; карта — исходный виджет 2ГИС. Их доступность зависит от сети.

Форма на внутренних страницах использует маску телефона исходника и демонстрационную валидацию. Данные не отправляются и не записываются в консоль. Кнопки записи и обратного звонка ведут к этому же блоку. Исходная главная сохраняет прежнее демонстрационное поведение форм. На внутренних страницах номер-заглушка +7 (495) 000-00-00 удалён, используется существующий +7 (904) 567-88-71. Кнопка маршрута передаёт адрес сервиса в Яндекс Карты. Юридические реквизиты в исходном подвале остаются заглушками.

Дополнительно проверены раскрытие/сворачивание моделей, подгрузка услуг, успешная демонстрационная валидация, слайдер и фильтр марок главной, закрытие мобильного меню при записи. Возврат Kia Rio → Kia кнопкой браузера проверен. Проверку «Вперёд» встроенный браузер завершил сообщением об отсутствии следующей страницы истории; этот сценарий требует отдельной проверки в обычном браузере. Код каталога не переопределяет историю браузера.

Скриншоты-референсы из ТЗ не были приложены. Использованы существующие компоненты и текстовые требования. Техническая применимость всех комплектаций, включая Rio, пока не подтверждена: не утверждаем наличие определённой коробки, ремня/цепи и двигателя. Перед публикацией нужны проверенные конфигурации, актуальность прайса, контактов и реквизитов, юридические документы и подключение отправки заявок.

Демо закрыто `noindex,nofollow`; метаданные содержат `indexable:false`. Для SEO-продакшена необходимы SSG/SSR/предрендеринг, корректные HTTP-статусы, проверенные canonical и разрешённый список индексируемых комбинаций. Массовая генерация и публикация не выполнялись.
