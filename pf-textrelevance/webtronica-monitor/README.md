# Мониторинг позиций и TR — Webtronica

Готовый автономный файл: `../webtronica-monitor.html`. Откройте его двойным щелчком в современном браузере. Подключение к интернету, установка пакетов и сервер не требуются. Стили, интерфейс и модель встроены в HTML.

## Что проверить

- **Просадки и релевантность:** раскройте строку «Габионы». Доля 52%, два приоритетных сигнала, TR 67 → 63. Оба условия относятся к одному событию.
- **Кнопка TR:** основная часть запускает новый анализ, стрелка открывает прошлый. Выполнение имитируется примерно 4–5 секунд. История пополняется.
- **Полный анализ TR:** кнопка со стрелкой внизу окна открывает модуль «Анализ TR» в новой вкладке (`target="_blank"`, `rel="noopener noreferrer"`). В прототипе используется предоставленная ссылка: `https://webtronica.io/dashboard/text-relevance-analysis/72?projectId=61`. При интеграции модуль передаёт `fullAnalysisUrl` для каждого результата; эта ссылка имеет приоритет над демонстрационной, в том числе при просмотре прошлых анализов.
- **Позиции:** звезда меняет приоритет; меню строки назначает Главный запрос и возвращает автоматический выбор. Поле !точной частотности редактируется.
- **Настройки:** сохраните новые пороги, режим и цели. Нажмите «Собрать позиции», чтобы проверить условия и создать события.
- **Уведомления:** колокольчик открывает события с причинами и переходом к объекту. Каждому новому сбору соответствуют новые события.
- **Первое включение:** откройте «Сценарии прототипа» внизу страницы. Выберите первое включение, включите мониторинг и сохраните. Начальные TR выполняются для шести подходящих объектов, в том числе в ручном режиме.
- **Автоматический TR:** отдельный сценарий переключает режим, выполняет сбор и запускает диагностику. Объекты без Главного запроса пропускаются.
- **Повторение:** «Все состояния — основной сценарий» возвращает демонстрационные данные. Все изменения хранятся локально в браузере.

## Демонстрационные состояния

| Объект | Состояние |
|---|---|
| Габионы | 52%, оба условия, Главный выбран вручную, нужен ручной TR |
| Заборы из габионов | 68%, норма, все цели TR достигнуты |
| Монтаж габионов | 65%, только приоритетный сигнал 7 → 11, TR выполняется |
| Сетка для габионов | 52%, только групповое условие, TR ниже цели |
| Камень для габионов | Первый результат 64, предыдущего TR нет |
| Матрацы Рено | Нет частотности; доступен ручной выбор Главного |
| Без группы · /gabiony-spb/ | Отдельный набор по URL, автоматический Главный |
| Без группы · /ustanovka/ | Нет частотности; TR не запускается |

В начальном демонстрационном сценарии выбран ручной режим, чтобы показать требующие действия кнопки. Первое включение вынесено в отдельный воспроизводимый сценарий. Изменение ПС или региона открывает независимый контекст данных. В новом контексте сначала нужно собрать позиции.

## Исходники и проверка

- `model.js` — расчёты, выбор Главного, события, очередь TR, демонстрационные данные.
- `app.js` — три экрана, фильтры, модальные окна и обработчики.
- `styles.css` — оформление в стилистике предоставленных скриншотов.
- `build.cjs` — сборка автономного HTML без сторонних зависимостей.
- `model.test.cjs` — 13 проверок правил и граничных случаев.

```sh
node webtronica-monitor/build.cjs
node --test webtronica-monitor/model.test.cjs
node webtronica-monitor/serve.cjs
```

Последняя команда необязательна: открывает локальное превью на `http://127.0.0.1:8787`.

Раскрывающиеся DEV-блоки содержат источники данных, правила, состояния и пограничные случаи. Все позиции, события и результаты TR демонстрационные; интеграции с Webtronica и реального сбора нет. Исходные файлы `seo-dashboard-prototype.html` и `seo-dashboard-lite.html` не изменялись.
