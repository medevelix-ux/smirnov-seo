# Maxima Hotels — HTML-прототип для GitHub Pages

Готовый статический сайт. Сборка, npm и серверная часть не нужны.

## Как опубликовать

1. Распакуйте `maxima-hotels-github-pages.zip`.
2. Создайте репозиторий на GitHub. Для бесплатного GitHub Pages используйте публичный репозиторий.
3. Загрузите **содержимое архива в корень репозитория**: `index.html`, папку `assets`, `.nojekyll` и этот README. Не загружайте ZIP вместо файлов и не помещайте сайт в дополнительную вложенную папку. При загрузке через браузер используйте **Add file → Upload files**, затем **Commit changes**.
4. Откройте **Settings → Pages**.
5. В **Build and deployment → Source** выберите **Deploy from a branch**.
6. Выберите ветку **main** (или ветку, куда загрузили файлы), папку **/(root)** и нажмите **Save**.
7. После окончания публикации откройте адрес, показанный в **Settings → Pages**. Обычно это `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Файл `index.html` должен находиться на верхнем уровне выбранного источника публикации. Все пути к ресурсам относительные, поэтому сайт работает и в подпапке репозитория, и на отдельном домене.

Официальные инструкции: [настройка источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), [создание сайта](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Что находится в архиве

```text
index.html                 Главная страница
.nojekyll                  Публикация статических файлов без Jekyll
assets/styles.css          Стили и адаптивная верстка
assets/app.js              Интерактивность прототипа
assets/images/             43 изображения: логотип, отели и статьи
assets/fonts/              Локальный шрифт Manrope и его лицензия OFL
README.md                  Эта инструкция
```

Сохранены дизайн, тексты и интерактивность исходного прототипа: пять слайдов, выбор отеля, форма с проверкой дат, карусель из 35 статей, мобильное меню, анимации, кнопка «Наверх» и сохранение принятия cookie-уведомления в браузере.

Изображения и шрифт загружаются из `assets`, без обращений к исходному сайту и Google Fonts. Для просмотра можно открыть `index.html` в браузере; для проверки поведения как на хостинге используйте любой локальный HTTP-сервер.

## Внешние сервисы и границы прототипа

- Форма «Найти номер» сохраняет исходное демоповедение: открывает официальный сайт выбранного отеля. Даты и число гостей в систему бронирования не передаются; бронирование на GitHub Pages не создаётся.
- Статьи, услуги, вакансии, юридические документы и переключение на английский язык ведут на официальные внешние страницы, как в прототипе.
- Интерактивная карта Яндекса загружается из интернета. При недоступности карты можно воспользоваться ссылкой «Открыть карту».

## Изменение сайта

Редактируйте разметку и основной текст в `index.html`, оформление в `assets/styles.css`, данные отелей, статьи и логику — в `assets/app.js`. При обновлении сохраняйте папку `assets` и имена файлов либо исправляйте соответствующие ссылки.

Исходные изображения перенесены с URL, указанных в предоставленном HTML. Лицензия шрифта: `assets/fonts/OFL.txt`.
